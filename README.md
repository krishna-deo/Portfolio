# Krishna Deo — Portfolio Website

A modern full-stack developer portfolio built with React, TypeScript, Tailwind CSS, and a Node.js backend contact API.

## Live Demo

Frontend: https://portfolioo-1-ybpn.onrender.com  
Backend API: https://portfolioo-7kuv.onrender.com

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Vite
- Framer Motion / animation effects

### Backend
- Node.js
- Express.js
- CORS
- Resend Email API

## Features

- Premium dark UI with emerald accent theme
- Responsive design for desktop, tablet, and mobile
- Smooth animations and interactive effects
- Project showcase with preview image
- GitHub and live demo project links
- Functional contact form
- Backend email API for receiving portfolio messages
- Clean component-based structure
